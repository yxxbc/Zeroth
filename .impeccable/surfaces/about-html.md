# about.html — surface brief

**Scope:** the product's single marketing/identity page (`about.html`).
**Visitor mode:** Persuade. **Platform:** web. **Build path:** code-led (flipped on the direction page; `.impeccable/config.json` records `code`).

## Audience and job

Someone who already lives in a terminal, deciding whether Zeroth earns a slot
beside the agents they run. Forwarded to colleagues who do not use a terminal,
so the offer must be legible cold. Action: copy the install command and run it.
Proof available: real transcripts and real counts from this repository.
