# 搜索摘要与工具详情

状态：实施设计，已确认采用方案 A。保留现有工具展开、Ctrl+O、键盘导航和全屏点击展开。

## 目标

搜索摘要说明搜了什么，以及返回输出能够证明什么。展开详情区分查询、分组结果和执行命令。
展示层不改写工具参数、输出、上下文或 rollout。

## 摘要

组内按搜索调用次数计数，不称为关键词数量。保留最近搜索的有界预览：查询与范围，以及仅在
命令和完整输出格式可识别时显示的结果统计。文件枚举标为文件，不当作内容匹配。
未知格式保留命令，不虚构结果数量。执行失败和无结果分开呈现。

## 展开结果

代码匹配按文件首次出现的顺序分组。每个文件标题只出现一次，源代码行号与代码对齐。
原始命令在结果之后单独成区。记录的退出状态和耗时继续作为独立的执行事实。
不增加新的详情页面。

联网搜索按独立行显示编号标题、来源提供的日期、完整链接和摘要。面向模型的重复边界指令
不作为搜索摘要展示，存储中的模型输出不变。未知或格式损坏的联网输出使用普通完整输出视图。

## 识别与回退

shell 识别器接受单条字面搜索命令与已知输出选项。管道、替换、含糊标志、不支持的输出模式
或无法解析的结果行回退原始命令与输出布局。展示识别不改变权限判定，不承担 shell 执行解析，
也不表示命令安全。

只有格式可识别且完整的匹配输出才报告准确匹配行数和文件数。输出截断时标为保留结果，
不称为完整总数。统计的是匹配输出行，而非同一行中正则表达式的出现次数。
已知无匹配退出码配合空输出显示无匹配，执行错误保留错误正文。不丢弃无法识别的二进制提示、
上下文分隔、文件标题或其他特殊记录。

## 布局与性能

宽度全部按显示列计算。长中文路径、URL 和源代码行换行显示，存储内容不变。
窄布局优先保留查询与结果身份，再显示次要信息。组预览限制行数与条目数，展开输出保持完整。
使用现有主题角色提供正文、路径/链接、行号与状态的对比度。

解析直接读取保留文本，不为长输出构造 JSON 树。保留 transcript 缓存的增量失效和可见窗口
渲染约定。格式损坏的结果不能留下仅渲染前半部分、隐藏剩余输出的视图。

测试覆盖调用计数、查询保留、文件分组、文件枚举、联网标题/链接/日期/摘要、未知命令回退、

不调用真实搜索服务。
