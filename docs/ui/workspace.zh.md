# 全屏工作窗口

通过 `--fullscreen` 或 `ZEROTH_TUI=full` 启动时可使用底部会话栏。默认的行内模式保留现有页脚和子代理列表的导航方式。

会话栏先显示主对话，再按列表顺序显示子代理，已结束的子代理在现有列表移除前也会显示。后台 Shell 不作为标签。实心圆点表示当前显示的会话，独立的高亮表示键盘焦点。屏幕较窄时，会话栏显示包含焦点或当前会话的部分标签。

| 输入 | 操作 |
| --- | --- |
| `↓` | 从空输入框进入当前会话标签。菜单、快捷键提示、弹窗、Shell 输入模式和历史召回保留原有键盘行为。 |
| `←` / `→` | 移动标签焦点，不切换会话。 |
| `Enter` | 显示焦点所在会话，焦点仍留在会话栏。 |
| `↑` / `Esc` / `Ctrl+C` | 返回输入框，不切换会话。 |
| 点击标签 | 直接切换到对应的会话。 |

切换标签会保留草稿、光标位置，以及各会话的滚动和展开状态。全屏 Shell 面板和输入接管尚未实现。
