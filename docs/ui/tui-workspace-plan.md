# TUI 工作窗口与会话切换

## 打开就是一个工作窗口

**阶段 1 已实现会话切换；其余窗口改进尚未实现。** 这里的工作窗口是 [`--fullscreen` 模式](full-screen.md)，不是当前默认的内联模式。以后可以让 Zeroth 默认打开一个像 Codex CLI 那样的终端内工作窗口，而不再不断往终端滚动历史里追加文本；切换默认值是单独的决定，不在这次工作窗口改动的范围内。

全屏已经有可滚动的内容区、固定在底部的输入框和状态栏；新内容在窗口内更新，退出后恢复 shell 画面。主对话和子代理共用同一个窗口；切换会恢复各自的草稿、滚动位置与展开状态，不另开终端页面。工具详情已经能在原处展开，输入首行滚出顶部后也可以置顶（见[工具详情与置顶输入](conversation-tool-details-and-pin.md)）。待完成的目标是：缩放窗口时保住阅读位置，点开工具详情时留住点到的条目，点击置顶行能定位到原输入。

## 主对话和子代理有固定的切换路径

**阶段 1 已实现。** 全屏底部会话栏按「主对话 → 子代理」排列，包含仍在列表中停留的已结束子代理。行内模式保留原有的后台 Shell 指示器和子代理名单导航。

在全屏模式，空输入框且没有菜单、快捷键提示、弹窗或正在使用的历史召回时，按 `↓` 聚焦当前会话标签。非空输入框和 Shell 输入模式保留原有行为。`←` / `→` 只移动焦点，`Enter` 切换并保留会话栏焦点，`↑` 返回输入框；点击标签也可直接切换。实心圆点标出当前会话，独立的高亮标出焦点。

后台 Shell 不列入会话栏，启动或退出不影响标签路径。

## 在主窗口查看和操作后台 Shell

**阶段 2（面板）和阶段 3（输入接管）尚未实现。** 行内模式的现有入口仍是[后台 Shell 指示器与 `↓` 管理器](../tools/background.md)。计划在工作窗口状态栏单独显示「后台 Shell」和运行数量，例如「后台 Shell · 2 运行中」。点击它或按拟议的 `Ctrl+G`，在同一个窗口内打开 Shell 面板，不必先按 `↓`。`Ctrl+G` 目前未绑定面板动作，仍需验证所支持终端和 tmux 中的按键传递；终端初始化只请求 `DISAMBIGUATE_ESCAPE_CODES`，不要求所有按键都以增强序列上报。`Ctrl+B` 仍用于把当前命令放到后台，不负责查看。

面板计划将「等待输入」「运行中」与「已结束」分开显示：「已结束」取自完成通知，不在运行任务列表里查找。点击任务，或用 `↑` / `↓` 选中后按 `Enter`，可查看实时输出或退出结果。已结束或不接受输入的任务只显示输出。

支持输入的任务计划在详情里提供「接管输入」。接管后，普通按键和粘贴只送给标明的 Shell，不进入聊天框；保留给应用的 `Esc`、`Ctrl+C`、`Ctrl+B`、`Ctrl+O` 不转发给 Shell，仍由应用按各自的规则处理。拟用 `Ctrl+G` 退出接管，回到只读详情，命令继续在后台运行。在浏览状态下，拟用 `Esc` 或 `Ctrl+G` 关闭面板，回到打开前的会话、阅读位置和焦点。Shell 等待输入或执行完成时，只在状态栏提示，不弹出面板、不抢焦点，也不改变会话切换顺序。
