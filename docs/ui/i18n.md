# Internationalization (i18n) Plan

> Status: Draft (deferred — documentation only, not yet implemented).

## Goal

Allow Zeroth's TUI chrome, slash-command descriptions, status/toast messages,
and built-in tool summaries to switch cleanly between English (`en`, default)
and Simplified Chinese (`zh-CN`, or auto-detected from locale / `/settings`),
without hurting startup latency, binary size, or `cols()` display-width
invariants.

## Architecture

1. **Locale selection & persistence**
   - Resolution order: `ZEROTH_LANG` env var → `~/.zeroth/settings.json`
     (`language`: `"auto" | "en" | "zh-CN"`) → `LC_ALL` / `LANG` (`zh_*` →
     `zh-CN`, else `en`).
   - Expose a **Language** row in `/settings` that updates `App::settings` and
     rebuilds cached UI strings immediately (no restart required).

2. **Compile-time typed catalog (`src/i18n/`)**
   - Avoid runtime JSON/YAML parsing on startup (keep cold-start under ~6 ms).
   - Define a `Locale` enum (`En`, `ZhCn`) and typed string tables or
     `const fn` / `match locale` lookup functions grouped by surface:
     - `chrome`: banner hints, status bar, footer, keybind hints, modals
     - `commands`: slash-command palette descriptions (`COMMANDS`)
     - `toasts`: info/error notices (`COPY_OK_NOTICE`, `RESUME_BUSY_NOTICE`, etc.)
     - `tools`: model-independent TUI headers/summaries (`Thinking…`, `Thought for …`, tool status labels)
   - Keep **model-facing** tool schemas, wire names, and system prompt authority
     rules in English unless the user's own `~/.zeroth/USER.md` / prompt
     instructs otherwise.

3. **Display-width & wrapping safety**
   - Every localized string passes through `cols()` (`unicode-width`) for layout
     and truncation (`truncate_to_cols`), never byte/char counts.
   - Slash-command descriptions in `COMMANDS` must remain within the palette's
     column budget (`palette_descriptions_are_concise_and_product_name_free`
     checked for every supported `Locale`).
   - `diff_buffers` wide-glyph shadow scrubbing (`src/term.rs`) ensures CJK
     labels inside highlighted/selected rows never leave trailing artifacts.

4. **Phased rollout**
   - **Phase 1**: Add `Locale`, `src/i18n/mod.rs`, `/settings` Language toggle,
     and localize the main banner, status line, footer hints, and toasts.
   - **Phase 2**: Localize `/commands` descriptions, overlays (`/context`,
     `/usage`, `/resume`, `/diff`, `/secrets`, `/skills`, `/hooks`), and
     permission / ask modals.
   - **Phase 3**: Add `zh` parity tests verifying no missing keys, no column
     overflows at 80-column terminals, and clean snapshot/smoke coverage.
