# `/diff` —— 评审项目的 Git 改动

`/diff` 打开一份全屏、只读的当前 Git worktree 评审。它可以从仓库根或其中的任何
目录使用，包括 linked worktree。不在一个 Git worktree 里时，它显示中性的信息
toast **Not a Git repository.**，并在不进入全屏阅读器的情况下保持对话开着。它
从不初始化仓库。

## 评审显示什么

**Git changes** 头标识出仓库，并概括它的改动。左侧的文件列表给出改动过的路径、
改动类别，以及新增/删除的行数。右侧的补丁显示选中的文件，带旧/新行号、高亮的新增
与删除，以及彼此分明的 hunk 头。聚焦的 pane 边框和页脚让人清楚哪个 pane 会响应
导航。颜色跟随活跃主题。

初始的 **All** 过滤器包含已暂存、未暂存和未跟踪的改动。已暂存的补丁把索引与
`HEAD` 比较；未暂存的补丁把工作区与索引比较。在两个地方都改过的文件会有各自独立
的条目，所以已暂存的工作与随后的编辑可以各自独立评审。未跟踪的文本文件以新增的
形式出现。被 Git 忽略的文件被排除。二进制的改动有一条可见的提示代替文本预览。
大的补丁与仓库使用有界预览，凡是内容被截断的地方都有明确的提示。

这份评审覆盖当前的本地改动，而不是提交历史，也不是与另一个分支的差异。一个干净
的仓库以 **Working tree clean** 打开。一个没有结果的过滤器或文件名搜索显示
**No matching files**。

## 导航

评审打开时文件列表有焦点。页脚保持主要控制项可见。

| 键 | 动作 |
| --- | --- |
| `1`、`2`、`3`、`4` | 显示 All、Unstaged、Staged 或 Untracked 改动 |
| `/` | 搜索文件名；打字即过滤列表 |
| 搜索中按 `Enter` | 保留文件名过滤并回到导航 |
| 搜索中按 `Esc` | 清除文件名过滤并回到导航 |
| `Tab` | 在 Files 与 Patch 之间切换焦点 |
| Files 中按 `Enter` | 聚焦选中文件的补丁 |
| `↑` / `↓`、`k` / `j` | 在聚焦的 pane 里移动 |
| `PgUp` / `PgDn` | 在聚焦的 pane 里移动一页 |
| `Home` / `End` | 跳到聚焦 pane 的开头或结尾 |
| `[` / `]` | 选择上一个或下一个文件 |
| `n` / `N` | 跳到下一个或上一个 hunk |
| `←` / `→` | 横向滚动补丁 |
| `r` | 重新加载当前的 Git 改动 |
| `q`、`Esc`、`Ctrl+C` | 关闭评审并回到对话 |

文件名搜索处于活动状态时，像 `q` 和 `r` 这样的字母是搜索文本。先结束搜索，再用
这份评审的字母快捷键。

## 加载与回到聊天

Git 跑在一个后台 worker 里，所以打开或刷新评审不会阻塞按键处理，也不会阻塞一个
运行中的对话。这个命令先在保持对话可见的情况下把当前目录校验为一个 Git
worktree。只有一个合法的 Git worktree 才会打开 alternate-screen 评审，在那里它的
改动在后台加载。在 Git 之外，命令显示 **Not a Git repository.** 而不打开加载屏。
刷新会让评审保持打开。文件改动之后按 `r` 取一份新快照。

阅读器使用终端的 alternate screen，从而保住内联对话与终端 scrollback。关闭它
恢复对话；`Ctrl+C` 关闭评审，而不是退出应用。终端尺寸变化会重算 pane 布局；窄
终端以整宽显示聚焦的那个 pane，用 Tab 在文件与补丁之间切换。

评审里没有任何控制项会暂存、取消暂存、编辑、恢复、提交或删除文件。

## 验证

`scripts/smoke/phases/120-diff.sh` 在一个隔离的 tmux 终端里、用已暂存/未暂存/
未跟踪的 fixture 演练这个命令。它覆盖过滤、文件名搜索、pane 与 hunk 导航、刷新、
改变尺寸、关闭、一个干净的仓库、在 Git 之外被拒绝，以及评审打开期间一个回合
结束。
一段原始终端录制验证被拒绝的非 Git 命令从不进入 alternate screen，而一次带样式的
抓取检查它那条中性信息 toast。评审前后的仓库快照验证导航没有改动索引与工作区
文件。
