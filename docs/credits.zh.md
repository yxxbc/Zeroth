# 技术致谢

除了 [README](../README.md#acknowledgements) 里致谢的那些项目，Zeroth 还使用
了这些协议、库和视觉资源：

- [Model Context Protocol](https://modelcontextprotocol.io)，那个把 agent 连到外部
  工具与服务的标准。
- [ratatui-image](https://github.com/benjajaja/ratatui-image)，用于在终端里渲染图片。
- [tokio](https://tokio.rs)，用于异步事件循环。
- [syntect](https://github.com/trishume/syntect) 与
  [two-face](https://github.com/CosmicHorrorDev/two-face)，用于语法高亮。
- OpenAI 的 [tiktoken](https://github.com/openai/tiktoken)，Zeroth 的 token
  估计是拟合着它的 `o200k_base` 和 `cl100k_base` 词表做的。
- [Catppuccin](https://catppuccin.com)、[Dracula](https://draculatheme.com)、
  [Nord](https://www.nordtheme.com)、[Gruvbox](https://github.com/morhetz/gruvbox)、
  [Solarized](https://ethanschoonover.com/solarized)、[Monokai](https://monokai.nl)
  和 One Dark，用于主题背后的配色。
